# Game Companion AI

Build something that is like the worlds smartest gamer that can watch you play, figure out your current status in the game and keep an updated memory of that while telling you what to do next as you play in real life all along the way. He should be able to tell you what to do next and you should be able to ask it or tell if you want to steer from the default objective of winning the game. It needs to give advice in real time and not slow down or lag the process for the player. He also needs to know glitches, tricks, secret things, Easter eggs etc
